# Термины

| Термин | Рабочее значение |
|---|---|
| Кейс | Отдельная задача с case_id, материалами, реестрами, артефактами и состоянием. |
| Решение | Выбор действия при ограничениях; рекомендация модели не равна утверждению человека. |
| Fact | Проверяемое сведение с сохранённым источником и точным локатором; истинность требует смысловой проверки. |
| Assumption | Явное рабочее допущение до получения данных; указаны влияние и условие проверки. |
| Hypothesis | Опровержимое предположение о механизме/поведении; связано с проверкой. |
| Forecast | Условный прогноз будущего с входами, формулой, горизонтом и ограничениями. |
| Synthetic | Искусственный учебный материал, число или реплика с synthetic=true; не реальное наблюдение. |
| Source | Сохранённая версия материала с ID, происхождением, хешем, датой и ограничениями. |
| Claim | Утверждение с ID, type, status и связями с доказательствами. |
| Locator | Точное место во фрагменте источника: строки либо таблица/строка/колонка и т. п. |
| Gap | Неизвестное/конфликт с влиянием на выбор и следующим действием; это реестр, не claim.type. |
| Status quo | Сохранение текущего положения с ценой бездействия и условиями пересмотра. |
| Closure | Закрытие существующего направления либо отказ от запуска нового с последствиями/обязательствами. |
| Capability | Конкретная возможность продукта; available/planned/unknown описывает доступность, а не доказанный эффект. |
| Promise | Внешнее обещание, связанное с capability, claim IDs, ограничениями и проверкой выполнения. |
| Baseline | Измеренная база сравнения; неизвестность требует baseline_plan и не равна нулю. |
| Guardrails | Метрики/условия нежелательных последствий, ограничивающие продолжение эксперимента. |
| Checkpoint | Завершённая неизменяемая версия state и артефактов с manifest хешей; после проверки — authority состояния. |
| Revision / operation_id | Версия состояния / ID операции для контроля конфликтов и идемпотентного повтора. |
| Approved decision | Запись реального ответа человека по текущему пакету вариантов; не проверка личности. |
| Needs_review | Данные/вывод/согласование требуют пересмотра; прежний выбор нельзя молча считать актуальным. |
| Структурная проверка | Проверка схемы, ID, связей и заполненности; не устанавливает смысловую истинность. |
| Смысловая проверка | Проверка, что конкретный фрагмент действительно поддерживает вывод в его границах. |
| Complete | Завершение текущей версии работы, а не доказательство рыночного успеха. |

Контрактные значения полей и операций смотри в [контракте реализации](../docs/IMPLEMENTATION_CONTRACT.md), правила классификации — в [evidence-policy](../instructions/evidence-policy.md).
