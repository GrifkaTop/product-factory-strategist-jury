# Продолжить кейс

Продолжи существующий кейс `⟨case_id⟩` из этой папки. Не создавай новый вместо него и не принимай память чата за сохранённое состояние.

Прочитай [AGENTS](../AGENTS.md) и [правила сохранения](../instructions/operating-rules.md). Из корня открытой папки проверь кейс командой `python -m tools.strategist checkpoint --case CASE_ID` и загрузи состояние через `status --case CASE_ID` того же CLI. Если ID не найден, проверь, открыта ли папка с нужным кейсом, и уточни ID или папку у пользователя. Единственная authority — проверенный checkpoint; outputs и отдельные JSON являются проекциями. Если получен recovery_warning, сообщи, какая версия восстановлена и что осталось неизвестным. Повреждение не скрывай.

Если `checkpoint` вернул `verified: false` и `recovered_verified: true`, текущий указатель не прошёл проверку. Покажи доступный снимок и ближайший сохранённый шаг в режиме чтения. Для возобновления записей потребуется исправить указатель или восстановить рабочую копию.

Если операция записи вернула `CheckpointCommitError`, сравни `attempted_revision` с `last_verified` и перепроверь `checkpoint` и `status`. Если требуемая версия уже текущая, сообщи подтверждённый статус. Если доступна прежняя текущая версия, повторяй исходный `apply` с тем же `operation_id` после устранения причины. Если доступен только резервный снимок, покажи его как доступный для чтения.

При неизвестном ID выполни `python -m tools.strategist cases`. Если подходят несколько кейсов, попроси выбрать. Резервные версии и недоступные кейсы показывай отдельно при выборе.

Прочитай только brief, актуальное решение, gaps, next_action и источники текущего шага. Кратко покажи: «Завершено … Стадия/status/revision … Ожидается … Изменилось … Следующий шаг …». Не повторяй законченный шаг без причины и не выдавай несохранённое за выполненное.

Запрос продолжить разрешает явное resume из paused; чтение само паузу не снимает. При awaiting_human сначала получи выбор. При needs_review установи затронутые зависимости и получи новое согласование существенного изменения. Пользовательский ответ не сочиняй. Повтор незавершённой операции не должен дублировать источник/решение. Сохрани следующий законченный шаг с актуальным expected_revision.
