# Стратег Фабрики продуктов

1. Откройте [демонстрационный проект](demo/README.md). Здесь один учебный кейс по брифу организаторов с исходными материалами и обеими стратегиями.
2. Откройте [описание со скриншотами](docs/project-description.pdf). Детали архитектуры и запуска есть в [README](README.md).
3. Чтобы проверить локальный запуск из корня, выполните `python -m tools.strategist doctor`. Для нового кейса откройте эту папку в Codex или совместимой среде и дайте агенту задачу по `AGENTS.md`.
