# Стратег Фабрики продуктов

ИИ-папка для руководителя цифрового продукта. Агент формулирует решение и план исследования, проверяет основания, сравнивает варианты и готовит согласованные продуктовую и коммуникационную стратегии. Существенный выбор остаётся за человеком. Агент сохраняет шаги и пересматривает выбор при изменении оснований.

**Для жюри** — [быстрый старт](START_HERE.md) · [демонстрационный проект](demo/README.md) · [описание со скриншотами](docs/project-description.pdf).

## Запуск

Нужен Python 3.11+. Локальный CLI работает на стандартной библиотеке без вызова модели. Откройте корень папки в Codex с доступной моделью либо в совместимой IDE и укажите `AGENTS.md` как инструкцию проекта. Для нового импорта PDF, DOCX и XLSX установите необязательные зависимости через `python -m pip install -r requirements-ingest.txt`. Текст и CSV обрабатываются без них.

Из корня можно проверить CLI:

    python -m tools.strategist doctor
    python -m tools.strategist cases

В свежей копии список пуст. Готовая демонстрация лежит в `demo/`. Чтобы начать кейс, передайте модели запрос:

> Начни новый продуктовый кейс по AGENTS.md и prompts/start.md. Задача: … Разрешённые материалы: … Сохраняй завершённые шаги и уточняй только то, что влияет на решение.

Для продолжения напишите «Продолжи кейс <ID> по prompts/resume.md». Агент сверит сохранённую ревизию и следующий шаг.

## Архитектура и ключевые решения

- [Правила](AGENTS.md), [методики](methods/) и [промпты](prompts/) направляют работу модели. [База знаний](knowledge/index.md) и [шаблоны](templates/) помогают подготовить проверяемые материалы.
- Модель сопоставляет источники, формулирует варианты и рекомендации. [CLI](tools/) проверяет структуру, воспроизводит вычисления и сохраняет версии. [Контракт инструментов](docs/IMPLEMENTATION_CONTRACT.md) описывает форматы и ограничения.
- Локальные папки `projects/` и `runs/` создаются при работе с кейсом. Проверенный checkpoint хранит состояние.
- [Семь навыков](skills/) охватывают интервью, обещания, дизайн пилота, пересмотр, бенчмарки, регрессии и замеры. [Протокол учебного сравнения](submission/benchmark-verification.json) показывает условия, время и баллы.
- Демонстрационный пример использует учебные данные брифа организаторов. Он обосновывает проверку пилота. Фактический эффект надо измерить.
