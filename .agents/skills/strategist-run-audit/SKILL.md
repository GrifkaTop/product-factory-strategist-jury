# Учёт прогона

До запуска зафиксируй идентификатор кейса и версию входов, среду, настройки модели и порядок сравнения. Для проверок вне рабочих журналов используй изолированный тестовый каталог. Сохраняй время по фазам, коды завершения, попытки, проверенные ревизии и помощь человека. Для оценки модели записывай фактически использованный профиль и наблюдаемые токены, включая кэш, только если среда их предоставила.

Разделяй время модели, локальных команд и ожидания человека. Сверяй счётчики и базу тарифа через `python -m tools.strategist measure --input FILE`. Различай оценку по тарифу, фактические платежи и квоту подписки. Неизвестные величины оставляй неизвестными. Сохраняй протокол без секретов и личных данных, со ссылками на набор входов и проверяемые результаты.
