## Запуск в Claude Code

Откройте корень распакованного проекта. Проверьте Python командой `python -m tools.strategist doctor`.
Для продолжения используйте `python -m tools.strategist cases` и затем `status --case ID` через тот же модуль. Если кейсов несколько, уточните ID перед изменениями.

В поддерживаемых версиях Claude Code хук `SessionStart` передаёт в контекст краткий список проверенных кейсов. Он не выбирает кейс и не снимает паузу. Для среды без поддержки хуков используйте `cases`.

Соблюдайте те же checkpoint, согласования и правила источников. Используйте доступную модель среды. План выбора GPT в документации относится к разработке в Codex. Рабочие процедуры можно открыть в `skills/` или, в архиве, в `.agents/skills/`.
