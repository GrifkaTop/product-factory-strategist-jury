# Демонстрационный проект «Связь для близких и собственных устройств»

Видеозапись показывает этот кейс, telecom-live. Пользователь попросил обосновать пилот помощи со связью и определить критерии его продолжения. Исходный материал — учебный бриф организаторов. Числа в нём относятся к вымышленному оператору.

Выбран пилот напоминания об оплате собственного номера на одном тарифе. Для оценки эффекта план сравнивает риск ограничения связи из-за неоплаты с обычным обслуживанием. Записанный прогон завершён на проверенной ревизии r10. Спрос, исходная частота ограничения и доступный поток клиентов требуют измерения.
