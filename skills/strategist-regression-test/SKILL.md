# Регрессионная проверка

Зафиксируй наблюдаемый сбой, вход и ожидаемое поведение до прогона. Выбери ближайшую штатную точку входа. Для CLI сохрани код завершения и проверяемые поля результата. Для ответов модели сохрани исходный ответ, рубрику и профиль модели. Сначала проверь изменённый путь, затем связанные проверки прежнего поведения.

Если проверка меняет состояние, используй одноразовый тестовый кейс в разрешённой копии. Проверь восстановление и повтор операции, когда затронуто сохранение. Для набора тестов репозитория запусти из корня `python -m unittest discover -s tests`. Раздели пройденные, упавшие и пропущенные проверки. Сохрани причины пропусков и условия, которые не удалось воспроизвести. Механическая готовность не подменяет оценку содержания.
