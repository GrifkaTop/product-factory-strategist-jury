# Пакет выбора человеку

Шаблон для `outputs/decision-memo.md`; `⟨…⟩` не заполнено. Основной пакет держи на одном экране, подробности — по ID.

Кейс: `⟨case_id⟩` · revision: `⟨revision⟩` · Дата: `⟨ISO8601 с TZ⟩` · Статус: **ожидается ответ человека**

Решаем: `⟨один конкретный вопрос⟩`. Рекомендуется: `⟨option ID и действие⟩`. После выбора: `⟨что агент подготовит; без подразумеваемого запуска/расхода⟩`.

| option ID / kind | Вариант | Главный довод | Сильное возражение / условие предпочтительности |
|---|---|---|---|
| ⟨ID / status_quo⟩ | ⟨вариант⟩ | ⟨claim IDs⟩ | ⟨содержание⟩ |
| ⟨ID / change⟩ | ⟨вариант⟩ | ⟨claim IDs⟩ | ⟨содержание⟩ |
| ⟨ID / alternative⟩ | ⟨вариант⟩ | ⟨claim IDs⟩ | ⟨содержание⟩ |
| ⟨ID / closure⟩ | ⟨вариант⟩ | ⟨claim IDs⟩ | ⟨содержание⟩ |

Три главных основания: `⟨claim IDs, смысл и ограничения⟩`. Два сильнейших возражения к рекомендации: `⟨содержание⟩`. Неизвестность: `⟨gaps⟩`. Цена ошибки и обратимость: `⟨последствия⟩`. Уверенность и условие смены рекомендации: `⟨почему⟩`.

Ответ человека: выбрать option ID, запросить проверку, изменить ограничения либо отложить. Отсутствие ответа ничего не утверждает.

## Заполнять только после реального ответа

| Поле `human_decision` | Значение |
|---|---|
| id | ⟨decision ID⟩ |
| selected_option_id | ⟨существующий выбранный option ID; не вывод модели из молчания⟩ |
| user_response | ⟨точный непустой ответ пользователя; до ответа оставить незаполненным⟩ |
| options_hash | ⟨SHA256 текущего списка options по контракту⟩ |
| rationale | ⟨основание выбранного решения; не вымышленная цитата пользователя⟩ |

Записано через `kind=human_decision`: `⟨подтверждённая revision и актуальность / ещё не записано⟩`. Это наблюдаемый ответ, а не проверка личности или согласование компании. История пересмотров: `⟨решение/причина needs_review⟩`.
